# Homebrew tap for graphrt

[graphrt](https://github.com/Graphrt/graphrt) is a small, fast runtime for agentic AI workflow graphs.

```sh
brew install graphrt/graphrt/graphrt
graphrt --version
```

The formula installs the prebuilt binaries from the graphrt GitHub releases
(macOS arm64/x86_64, Linux arm64/x86_64). It is generated by
`packaging/homebrew/render-formula.sh` in the graphrt repository for each release.
